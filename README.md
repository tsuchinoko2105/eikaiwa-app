# 日常英会話アプリ

日常生活でよく使う英会話フレーズを、フラッシュカードとクイズで練習できるシンプルなWebアプリです。

## 主な機能

- カテゴリ別(挨拶、買い物、レストラン、道案内、旅行、電話、雑談、仕事、トラブル対応、病院・薬局、銀行・郵便局、美容院、オンライン会議、引っ越し・住居)のフレーズ一覧
- レベルフィルタ(初級 / 中級 / 上級 / すべて)
- フラッシュカードで英語・日本語訳・使い方メモを確認
- 端末の音声合成機能を使った発音再生(通常速度 / ゆっくり)
- マイクを使った「話す練習」— 発音を音声認識で判定し、一致度をフィードバック(要 Google Chrome、マイク許可)
- カテゴリごとの短い会話練習モード — 相手役はTTSで自動再生、あなたの番はマイクで話して判定
- 覚えたフレーズのチェックと進捗表示
- カテゴリごとの4択クイズ

## 使い方

追加のビルド手順やインストールは不要です。`index.html` をブラウザで開くだけで利用できます。

```bash
open index.html
```

| ファイル | 内容 |

| `data.js` | カテゴリとフレーズのデータ |
| `dialogues.js` | 会話練習用の短いダイアログデータ |

| `js/views.js` | 画面切り替え |
| `js/speech.js` | 発音(音声合成) |
| `js/recognition.js` | 音声認識・発音判定の共通ロジック |

| `js/quiz.js` | クイズ |
| `js/conversation.js` | 会話練習モード |
| `js/main.js` | 初期化 |

## データについて

進捗(覚えたフレーズ)はブラウザの `localStorage` に保存されます。サーバーへの送信は行いません。

## 音声認識について

「話す練習」「会話練習」はブラウザの `SpeechRecognition` API を使用します。対応しているのは Google Chrome / Microsoft Edge のみで、Safari・Firefoxでは非対応です。初回利用時にマイクの使用許可を求められます。音声はブラウザ標準の認識機能を通して処理され、このアプリ自体が録音データを保存・送信することはありません。

### マイクを使う場合は `file://` で直接開かない

`index.html` をダブルクリックして `file://` で開くと、Chromeがそのオリジンへのマイク許可を記憶できず、話すボタンを押すたびに許可ダイアログが出てしまいます。ローカルサーバー経由(`http://localhost`)で開けば、一度許可すれば次回以降ダイアログは出ません。

```bash
cd "日常英会話アプリ"
python3 -m http.server 8888
```

上記を実行したまま、ブラウザで `http://localhost:8888/index.html` を開いてください(サーバーを止めるには `Ctrl+C`)。
